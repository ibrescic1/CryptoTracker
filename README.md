# Crypto Tracker

A simple cryptocurrency tracking web application built with Node.js,
Express, Axios and EJS.

## Features

- Search and select cryptocurrencies
- Display current price
- Display 24h price change
- Display market capitalization
- Display 24h high and low
- Display 24h trading volume
- Error handling for unavailable cryptocurrencies

## Technologies

- Node.js
- Express
- Axios
- EJS
- CoinGecko API
- Tom Select

## Installation

1. Clone the repository
2. Install dependencies:

npm install

3. Start the application:

node index.js

4. Open:

http://localhost:3000
